# AutoCore ERP - Parts & Service Management

The ultimate ERP solution for automotive parts and service management. Streamline your workshop, manage inventory, and track sales with ease.

## Key Features
- **Dashboard**: Real-time business insights and key metrics.
- **Inventory**: Comprehensive stock management with low-stock alerts.
- **Services**: Efficient ticket management for vehicle repairs and maintenance.
- **Transactions**: Secure record-keeping of all sales and service activities.
- **Mobile Optimized**: Fully responsive interface for on-the-go management.

## Tech Stack
- React + Vite
- TypeScript
- Tailwind CSS + Shadcn UI
- Lucide Icons
- Sonner (Toasts)

## Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Build for production: `npm run build`
